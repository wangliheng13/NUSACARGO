App Router dan Pages Router adalah dua sistem routing di Next.js dengan perbedaan mendasar. Pages Router menggunakan folder pages/, di mana setiap file otomatis menjadi route (pages/about.js → /about), dengan komponen default sebagai Client Component dan data fetching lewat fungsi khusus seperti getServerSideProps (render per-request) dan getStaticProps (static generation). Layout diatur manual via _app.js dan _document.js. App Router menggunakan folder app/ dengan file page.js wajib di setiap route (app/about/page.js → /about), dan secara default merender komponen sebagai Server Component—lebih hemat JavaScript di browser—sehingga komponen interaktif harus ditandai "use client". Data fetching cukup dengan async/await langsung di komponen, tanpa fungsi khusus, dan Next.js otomatis mengatur caching lewat opsi fetch. Layout menggunakan file layout.js yang bersifat nested dan tetap "hidup" (tidak re-render) saat navigasi antar halaman dalam segmen sama. App Router juga menambahkan fitur bawaan seperti loading.js (Suspense), error.js (error boundary), not-found.js (404 kustom), route groups, parallel routes, dan intercepting routes. App Router adalah arah pengembangan resmi Next.js dan direkomendasikan untuk proyek baru, sedangkan Pages Router masih didukung penuh untuk proyek lama; keduanya bahkan bisa dipakai bersamaan untuk migrasi bertahap.
